# 📊 Superstore Sales Dashboard (Power BI)

## Project Overview
This project is an interactive **Power BI Sales Dashboard** built using the Sample Superstore dataset. It provides insights into sales, profit, regional performance, and product categories through interactive visualizations.

---

## Features
- Sales & Profit Overview
- Monthly Sales Trend
- Region-wise Sales Analysis
- Category & Sub-Category Performance
- Interactive Filters (Slicers)

---

## Tools Used
- Power BI
- Microsoft Excel / CSV
- DAX
- Power Query

---

## Key Insights
- West region recorded the highest sales.
- Technology category generated the highest profit.
- Some sub-categories incurred losses despite high sales.
- Sales showed seasonal trends over time.
